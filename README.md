# 小红书原生界面前端原型

以提供的三张截图为参考，使用 HTML、CSS 和原生 JavaScript 实现双列信息流、笔记详情和滚动评论区。无第三方前端依赖。

## 运行

```sh
npm run dev
```

打开 http://localhost:5173 。手机端全屏适配，桌面端展示手机大小的画布。

点击任意卡片进入详情。在信息流下滑可找到「M Stand新出的盲盒有人懂吗」，也可直接访问 http://localhost:5173/#note/coffee 。详情向下滚动可看到标签和评论。点击底部评论按钮可直接定位评论区。

已实现：返回时保留信息流位置、图片左右触摸切换与方向键切换、关注、点赞、收藏、关键词搜索、标签面板、评论发布、回复、回复展开和复制分享链接。互动数据保存在当前页面内存中，刷新后重置。市集、完整个人主页、视频播放和创作流程不在当前原型范围内。

图片来源：参考截图中的原始内容通过 CSS 图片窗口展示，周边补充图片来自 Unsplash，头像来自 pravatar。外部图片需要网络。咖啡图集的补充图片是示例素材，并非原笔记的完整图集。
